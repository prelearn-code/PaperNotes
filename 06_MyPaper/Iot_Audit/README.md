## 建议阅读顺序

1. 先读核心方案 A、D、E、G、H，确认两项候选贡献、强基线和停止条件。
2. 再读任务书的第 1、4、5 节，按依赖执行 T00–T12。
3. `paper_cn.md` 仅用于保留已有正文、公式和参考文献，不作为当前实现规范。

## 当前研究结论

论文候选主线为：

1. 业务恢复损失约束下的审计预算配置；
2. 可启动目录布局与审计预算的联合配置；
3. 同一当前快照下的认证解析与条件性组合恢复，作为安全和实例支撑。

目前这些是待验证贡献。优先完成恢复语义、真实后端成本、固定 REP/META 与加权条带强基线、有限配置器。若强基线已经达到相同效果，收缩第一项贡献；若目录实验只有常规分页成本曲线，把第二项降为系统设计支撑。

## 目录内容

- `reference/`：本地参考论文 PDF。
- `数据集评估/`：数据画像及其可追溯记录；当前画像不是最终编解码或协议实验。
- `pic/`：旧版图表。旧图不能支持当前核心方案，重跑实验后再替换。

## 维护规则

- 核心设计只修改 `核心方案.md`，实施计划只修改任务书；不要再新建日期版“审查/路线/修改建议”文档。
- 阶段性结论写入任务书对应任务的状态和验收记录；稳定的协议结论同步到核心方案。
- 定量结论进入论文前，必须能追溯到代码提交、输入与配置哈希、随机种子和原始结果。
- 论文正文的完成式主张不得超过核心方案 H 节及任务验收状态。
