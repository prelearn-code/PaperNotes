## 1. 判定标准

必要条件（同时满足才值得投入 L2）：

| 编号 | 条件 |
|---|---|
| N1 | 形式模型显式允许服务器伪造应答（出现"审计时诚实执行""半诚实 CSP"即不满足） |
| N2 | 响应存在可缓存的低维充分状态（固定投影、逐块摘要、公开标签等） |
| N3 | 该状态比特数小于诚实服务器状态 |
| N4 | 可用真实群运算/配对做缩减参数 L2 |

排除项：**E1** 诚实执行假设；**E2** 半诚实模型；**E3** 信任根转移（TEE、经济押金、阈值诚实多数）；**E4** 纯功能组合。

## 2. Zhang Qingyang 2025：塌缩与攻击

### 2.1 原文定位（PDF 页序）

- **PDF 第 4 页**（刊物 1720），威胁模型：*"**Semi-honest CSP**: In cases where stored file data is lost due to hardware issues or other potential problems, the CSP, to maintain its reputation, might claim to have stored the data well and **forge false audit proofs during an audit**."*
- **同页**：*"The initial uploader sends the ciphertext, file tags, authentication tags, and **audit keys** to CSP."* → CSP 持有审计密钥 `{x_t, s_t}`。
- **PDF 第 7 页**（刊物 1723），Eq. (7)(8)：

```
p_{a_i} = Σ_{i=1}^{l2} x_t · b_i · c_{a_i,j}        (1 ≤ j ≤ s)
Ψ̂ = (Π_{i=1}^{l2} τ_{a_i}^{b_i})^{s_t · x_t}
Γ̂ = (Π_{i=1}^{l2} H_4(c_{a_i} || a_i)^{b_i})^{x_t}
Proof = {Γ̂, Ψ̂, {p_j}_{1≤j≤s}}

ϑ̂ = Σ_{j=1}^{s} p_j
e(Γ̂ · χ^{ϑ̂}, pk_{t,f}) = e(Ψ̂, g_1)                (8)
```

- **PDF 第 8 页**（刊物 1724），其安全性论证（Eq. (9)）只比较 `ε ≠ ε'`：即只排除"伪造密文与标签"的服务器，未讨论保留哈希、块和与标签的服务器。

### 2.2 塌缩为什么成立

验证式 (8) 只使用 **`ϑ̂ = Σ_{j=1}^s p_j`**，也就是说逐 sector 聚合在校验前先被**求和**掉。因此

```
ϑ̂ = Σ_j Σ_i x_t b_i c_{a_i,j} = x_t · Σ_i b_i · z_{a_i},     z_i := Σ_j c_{i,j}
```

服务器返回的 `p_1,…,p_s` 只需满足"总和等于正确的 `ϑ̂`"，具体如何分配不影响校验。于是保留状态可以退化为：

```
Z = { 每块哈希 H_4(c_i||i), 每块 sector 和 z_i, 原认证标签 τ_i, 审计密钥 {x_t,s_t} }
```

### 2.3 攻击步骤（无需密文）

1. 诚实上传后，服务器计算 `h_i = H_4(c_i||i)` 与 `z_i = Σ_j c_{i,j}`，保存二者与标签 `τ_i`，**删除全部密文分块**。
2. 收到挑战 `Chal={r_3,r_4,l_2}` 后按原文公式算出挑战下标 `a_i` 与系数 `b_i`。
3. 计算
   - `Γ̂ = (Π h_{a_i}^{b_i})^{x_t}`（用缓存哈希与自持审计密钥）
   - `Ψ̂ = (Π τ_{a_i}^{b_i})^{s_t·x_t}`（用保存的标签）
   - `ϑ̂ = x_t · Σ_i b_i z_{a_i}`（用缓存块和）
4. 提交 `Proof = {Γ̂, Ψ̂, {p_1,…,p_s}}`，其中 `p_1 = ϑ̂`、其余为 0。校验者算 `Σ_j p_j = ϑ̂` 并通过 Eq. (8)。

**最小充分状态**：每块一个哈希 + 一个 `Z_p` 元素；诚实状态为每块 `s` 个 `Z_p` 元素。当 `s ≥ 3` 时状态确实变小（N3 成立）。恢复原密文需要求 `H_4` 的原像，与块和一样都不可能由缓存单独给出。

### 2.4 与 Song 案例的关系

两例都是"固定投影型"（§2.1 类），但缺陷位置不同：

| | Song 2025 | Zhang Qingyang 2025 |
|---|---|---|
| 投影 | 标签内 `μ^{Σ_j c_ij}` | 标签内 `g^{Σ c}` + 块哈希 |
| 验证者是否也抹掉逐方向结构 | 否（逐块聚合仍由 `π(θ‖ID_F,i)` 区分） | **是**（Eq. (8) 先 `Σ_j p_j` 再校验） |
| 服务器是否持有审计密钥 | 不适用 | **是**（原文主动交付） |
| 刊物 | IEEE TC | IEEE TC |

因此 Zhang 的实例比 Song 更直接：**验证方程本身不区分 sector 方向**。

## 3. 正确构造（对照，非候选）

- **Yang Xiaodong 2026**：`σ_i = K_dos·(H_4(η‖SK_F‖i)·g^{Σ_j a_j c_ij})^{α_DO}`，与 Song 同形；但 `A_j = g^{a_j}` 公开而 `a_j` 仅 DO 已知，且证明返回逐 sector 聚合 `μ_j`。原文第 322 行自行论证：伪造 `u_j ≠ u'_j` 需要 `Σ_j a_j(u_j−u'_j)=0`，而 `(a_1,…,a_s)` 对 CSP 未知，概率 `≤1/q`。**这正是"独立方向 + 逐方向聚合"这一修复规则的文献依据。**
- **Miao Ying 2025（IEEE TDSC）**：认证标签 `σ_ij = sk_ID·[H_3(ID_i‖j)·g^{Σ_k a_k b_ijk}]^x`，公开参数含 `{A_k = g^{a_k}}`；证明返回 `{T^(t), {μ_k}_{1≤k≤s}}`，逐 sector 聚合。与 Yang 同类，属正确构造；其对抗者 `A_3` 明确定义为"试图伪造审计证明"。

两篇合起来说明：**该修复在文献中已存在**，因此贡献三不能把"换成独立底数"当作新机制。
